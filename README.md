# Desktop Utility Pro - The Ultimate Workspace

**Desktop Utility Pro** is a comprehensive, offline-first desktop application engineered to replace dozens of individual tools and web subscriptions. Built with a sleek, dark-themed `customtkinter` interface, it features over 10 dedicated "Studios" packing more than 100 essential utilities for developers, creators, marketers, and power users.

## 🚀 Features & Studios

### 📑 PDF Studio
Manage, convert, edit, and secure your PDF documents.
*   **Organize**: Merge, Split, Delete Pages, Rearrange, Rotate, Crop, Compress.
*   **Convert**: PDF to Word/Excel/PPT/CSV/TIFF/EPUB, and URL/Images to PDF.
*   **Security & Data**: Encrypt, Decrypt, Add Watermark, Remove Watermark, Sign, Translate, Extract Text.

### 🖼️ Image Studio
AI-enhanced image manipulation and bulk processing.
*   **Enhance**: AI Background Removal, Upscale, Unblur, Face Blur.
*   **Manipulate**: Resize, Crop, Flip, Round Corners, Add Borders, Pixelate, Brightness/Contrast.
*   **Format Conversion**: Native support for HEIC, WEBP, SVG, TIFF, PSD, GIF, PNG, JPG.
*   **Generative/Creative**: Extract text (OCR), Create Collages, Extract Color Palettes.

### 🎬 Video & 🎵 Audio Studios
Full-fledged local media manipulation and cloud downloading.
*   **Cloud Downloader**: Universal media downloader for YouTube, Twitter, TikTok, and Instagram via `yt-dlp`.
*   **AI Transcription**: Automatic Speech-to-Text for video and audio files.
*   **Video Processing**: Merge, Trim, Compress, Convert, Extract Audio/Thumbnail, Add Watermark/Music, Reverse, Speed change, Video to GIF.
*   **Audio Processing**: Convert, Trim, Join, Adjust Volume, Fade In/Out, Noise Reduction, Normalize.

### 📝 Office Suite (Word, Excel, PowerPoint)
Fully interactive rich text editors mimicking Microsoft Office.
*   **Word Studio**: A complete rich text editor supporting Bold, Italic, lists, text colored highlights, image/table insertion, and `.docx` save/load.
*   **Excel Studio**: Interactive scrollable spreadsheet grid with a formula bar, cell formatting, multi-sheet support, and `.xlsx` integration via `openpyxl`.
*   **PowerPoint Studio**: Slide manager with interactive visual previews, layout selection, and `.pptx` creation.

### 🗄️ File & Data Studio
Data structures simplified.
*   **Splitters**: Safely chunk massive CSV and Excel files into smaller parts.
*   **Converters**: Convert between XML, JSON, CSV, and Excel effortlessly.

### 📷 Passport Photo Studio
Create print-ready passport sheets without Photoshop.
*   **Flow**: Upload Photo → AI Background Removal → Apply Solid Color → Crop to standard dimensions (2x2", 35x45mm) → Generate A4 Print Sheet → Export as PDF/JPG/Word.

### 🛠️ System, Text & QR Studios
*   **System Tools**: Bulk Rename, Find Duplicates, Clean Empty Folders, File Hash, Disk Usage, Color Picker, Base64 Encode/Decode.
*   **Text Tools**: Word Counter, Case Converter, Find & Replace, Remove Extra Spaces, Lorem Ipsum Generator.
*   **QR Studio**: Generate and read QR codes.

## 💻 Installation

1. **Prerequisites**: Ensure you have Python 3.9+ and `ffmpeg` installed on your system path.
2. **Clone/Download** this repository.
3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   pip install yt-dlp SpeechRecognition pydub
   ```
4. **Run Application**:
   ```bash
   python main.py
   ```
